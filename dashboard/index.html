How the value is built — one fitted curve

log(market cap) = a + b × log(TVL)

Fitted by ordinary least squares on the restricted comps at run time — token protocols with a market cap and TVL above zero, minus wrapped, staked and bridged products (Bridge, Canonical Bridge, Liquid Staking, Liquid Restaking, Restaked BTC, CEX) and versioned names. Implied value is exp(a + b × ln(TVL)); the slope is below 1, so the curve is sublinear and ranking is TVL-monotone by construction. Growth, age and chains were tested as extra terms and dropped: growth's fitted sign flips by split, age makes the blind error ×6.0, chains carry a negative coefficient.
